# الحسابات الذكية PRO

تطبيق ويب تقدمي (PWA) باللغة العربية وواجهة RTL لإدارة العمليات المالية، الحسابات، العملاء والموردين، والتقارير حسب العملة.

## التشغيل
- انشر محتويات المستودع على استضافة تدعم HTTPS (مثل GitHub Pages).
- افتح الموقع مرة واحدة عبر المتصفح، ثم اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق**.
- يعمل التطبيق دون اتصال بعد تحميل ملفات التطبيق أول مرة.
- البيانات محفوظة محلياً في المتصفح على الجهاز نفسه. استخدم صفحة التقارير لتصدير نسخة JSON واستعادتها.

## ملاحظة
هذه النسخة تجهز تطبيق الويب القابل للتثبيت؛ لا تتضمن ملف Android APK جاهزاً. كلمة المرور/المزامنة عبر أجهزة متعددة ليست جزءاً من هذه النسخة. احفظ النسخ الاحتياطية في مكان آمن.
